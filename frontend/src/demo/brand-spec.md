# KnowFlow Demo Brand Spec

- Product: KnowFlow, a private course knowledge-base agent for big-data learning.
- Mark: the accepted v0 uses a provisional code-native `K` monogram and the KnowFlow wordmark. A final production logo asset is still pending.
- Primary ink: `#18211d`.
- Semantic accents: green for trustworthy/local, blue for evidence, amber for attention and learning progress.
- Materials: Liquid Glass is reserved for navigation, inspectors, toolbars, and interactive controls. Long-form reading surfaces use a higher-opacity background.
- Typography: system Chinese sans-serif for UI and reading; system monospace for status, versions, and evidence metadata.
- Shape: 8-12px controls, 18-22px large glass containers, circular icon controls where familiar.
- Motion: 180-240ms pointer response and view transitions; reduced-motion mode removes nonessential movement.
- Accessibility: high-contrast glass variant, visible focus rings, touch targets expanded on mobile, and no information encoded by color alone.
